# 产品概述

> 基于《AI Native 文档解析平台 · 系统设计文档 v1.0》整理

---

## 产品定位

AI Native 文档解析平台致力于为 Agent 和 RAG 知识库开发者提供多模态数据解析能力，将企业文档、图片、文本等多种格式转换为结构化的 Markdown / JSON 数据，为下游的知识库构建、智能检索和 Agent 应用提供高质量的数据底座。

## 目标客户

- **Agent / RAG 开发者** —— 需要将各类非结构化文档解析为结构化数据，以构建知识库和 Agent 应用
- **企业决策者** —— 希望通过企业级 Agent 降低运营成本、提升效率，需要可靠的数据解析平台作为基础设施

## 部署模式

私有化部署为主，以 Docker 容器化交付，支持单机 GPU 服务器运行。

## 核心业务范围

- 多模态数据摄入（文件上传 / 截图粘贴 / 文本粘贴）
- 文件类型识别（4 层级联管道）
- 多模态数据解析（文档解析管线 + 图片解析管线）
- 统一输出（Markdown / JSON）
- 任务管理与收藏管理

> 注：音频解析、视频解析属于预留扩展，当前不实现，但已定义接口协议。
